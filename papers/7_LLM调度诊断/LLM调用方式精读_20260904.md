## 二、四种用法的成本/可靠性结论（附数字）

1. **单轮打包**（RCACopilot）：每案 2 次调用、4.2 秒，Micro-F1 0.766（远超微调 GPT-3.5 的 0.103）。成本最低最稳，但依赖人工 handler 和固定类别。
2. **agentic 多轮**（RCAgent/mABC/CloudOpsBench）：每 episode 5-16 次工具调用。
   - 工程加固的价值：RCAgent 把 ReAct Pass Rate 86.3%→99.4%、Invalid 率 22.8%→7.9%；**小模型 greedy 是生命线**（换 nucleus 采样崩到 70.2%）。
   - mABC 多 agent+投票：平均分 38.5→64.9。
   - 通病（CloudOpsBench）：GPT-5 答对(JRA 0.68)但证据链闭合率仅 0.15-0.38；难度 Easy→Hard 时 JRA 0.73→0.30。
3. **进化循环**（OPRO/EoH/ReEvo）：离线摊销成本。EoH 约 2000 次查询 vs FunSearch 约 100 万次；ReEvo $0.06/轮；反思文本比 fitness 数值提供更平滑的"语言梯度"。
4. **翻译-求解**（LLM+P）：2 次 LLM 调用+规划器，成功率 66-100% vs 纯 LLM 0-35%；瓶颈全在翻译漏条件——LLM-Modulo 补的就是"批评回灌再生成"这个环。

## 三、训练类唯一代表：LogReasoner 配方

GPT-4o temp0.8 产 CoT → DPP 选 1000 条多样样本做 thought-SFT → 学生自解题、答案对的第二轮 SFT、答案错的由 GPT-4o 定位首个出错步改写（排除法重构）构成 **DPO 偏好对** → LLaMA-Factory 训 Qwen2.5-1.5B/7B（SFT bs16/lr3e-5/5轮；DPO bs4/lr5e-6/5轮）→ 8B 学生超 GPT-4o 达 14.65%。与我们"反事实 DPO"的差异：它的偏好对来自教师改写，我们的来自引擎 ΔKPI 实测——更硬。

## 四、最值得抄的 5 个工程细节

1. **JsonRegen**（RCAgent §3.3.1）：解析失败→让 LLM 先转写 YAML→按同结构重生成 JSON，循环至可解析；配合 Pydantic 参数校验双保险。
2. **OBSK 观测快照**（RCAgent §3.1）：上下文只放观测头部+hash，agent 引用时按 hash 查 KV 库取全文——上下文可控且无截断损失；轻量替代是 RCACopilot 的"先摘要到 120-140 词"（消融 +0.077 F1）。
3. **时序衰减 few-shot 检索**（RCACopilot §4.2.2）：Sim=1/(1+L2)×e^(−0.3Δt)，K=5 跨类别；选项表加 "Unseen" 兜底防强猜。
4. **轨迹级 self-consistency（TSC）**（RCAgent §3.4）：greedy 共享前缀、只在 finalize 分叉采样，省 token 留多样性；10-20 样本到平台期。
5. **反思即记忆**（ReEvo/ReflecSched/LLMHeurFromTraces）：经验蒸馏成短文本按需载入；ReflecSched 仅动态事件时刷新省 15% token；LLMHeurFromTraces 让 agent "查询"trace 库而非全量塞入。

## 五、对我们方向7的映射（现状 vs 应抄）

| 设计点 | 我们现状 | 应抄 |
|---|---|---|
| 输出格式强制 | 词表+JSON 提示（约定） | JsonRegen 循环 + Pydantic 校验（RCAgent/CloudOpsBench） |
| 证据打包 | 固定 4-8k 档案 | OBSK 式 hash 引用（agentic 版）或摘要级打包（单轮消融版） |
| few-shot | 无 | 时序衰减检索历史诊断案例 + Unseen 兜底（词表已有，机制补上） |
| 多样性 | 单次贪心 | TSC：共享前缀、答案处分叉采样 10-20 条 LLM 聚合 |
| 经验记忆 | 无 | ReflecSched 式对比经验文本，事件触发刷新 |
| 训练 | 二级阶梯=反事实DPO | LogReasoner 配方可参考；偏好对来源我们更硬（引擎ΔKPI vs 教师改写） |
