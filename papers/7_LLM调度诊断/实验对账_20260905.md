## 1. 方法论 v0.2 三项增补的对账

### 1.1 hard 视图三道质检防线 —— **被支持，且优先级上调**
F2 的论文表述是"abduction 缺口"（`article_llmdiag_v2_cn.tex` v2.1）。但 v0.2 §1-5
自己指出：若 hard 视图把判别性签名抹平（活锁振荡被均值平滑），塌陷可能是"题坏"
而非"溯因失败"。当前 cases_v2 的签名确认是在**完整数据**上做的（P1交付 §核验器战果），
**回溯义务未履行** → F2 的归因（题坏 vs 难）**尚未可判**。
**动作**：按 v0.2 三防线对 104 案例做 hard 视图复验（签名复验→可辨识性→CF−INT 兜底），
被拒案例移出正式集；复验通过前，论文 F2 处加"pending hard-view QC"限定语。
此步零 API 依赖，建议排在 frontier 之前——它决定主表是否返工。

### 1.2 CF−INT 兜底归因 —— **被支持（正是 F2 的裁判）**
若 INT 档（公开故障参数）成绩同样崩 → 塌陷确属溯因；若 INT 显著好于 hard →
塌陷一半来自"信息形态"。注入案例已带 `fault_delta_makespan`（P1交付），INT 判分
管线与反事实执行器同批交付（`llmdiag/v2/counterfactual.py`，本次新增）。
**动作**：INT 档 104 案例判分补齐（规则臂即可先行）。

### 1.3 粒度阶梯（L1/L2/L3）与信息二维网格 —— **被支持（F1 把活路指向观测形态）**
F1（8B<4B<<规则）说明**模型规模轴已走到负向**；F2 说明**观测形态轴**（同题不同视图）
有 0.596→0.413 的真实落差。v0.2 的粒度×预算网格恰好把实验力从"换模型"挪到"换观测"，
方向正确。G1.1（Granger 跑 L1–L3）作为"统计方法吃不到观测形态红利"的对照点
（`RCA前沿借鉴` §三-H4）随之升值。
**动作**：维持 v0.2 顺序；L1 档素材已在 episodes 原始记录中，构建器升级即可。

### 1.4 L4 显著性引导档 + 神经检测器第四臂 —— **被支持（F3/F4 是它的靶子）**
- F4（基率忽视：干净基线被过度诊断 30+/34）恰是"在无故障基线上无监督训练的重构误差
  检测器"的强项——L4 单臂有望在 baseline 类上直接压制过度诊断，且天然弱于 Unseen
  （v0.2 §1-6 已预注册该弱点），与 LLM 逃生舱行为成对对照。
- F3（忠实 0.97–1.0 与正确率无关）说明"指路人"必须**只指不证**（v0.2 两条硬约束）
  —— LLM 引用纪律已好（忠实度高），缺的是"先看哪"。L4 顺序重排与 F3 不冲突。
**动作**：按 v0.2 §7-⑦ 排 P2 后半；训练数据就用 34 条 baseline 轨迹（episodes 已存）。

## 4. 交叉验证注记（平行线收敛证据）

本次更新同时并入了一条**独立实现的平行线**（另一会话在 `0901icaps1` 分支重建的
闭环套件，24 案例 greedy 单臂 pilot，`实验对账` 同期入库：`papers/7_LLM调度诊断/
出题判卷闭环报告_20260904.md`）。两套独立代码得到方向一致的结论：
- 规则基线 easy→hard 塌陷：0.596→0.413（主线 104 案例）与 0.812→0.625（平行线 16 案例，
  定位口径）**方向一致**；
- 平行线同样独立发现 greedy 臂两要素（obs_radius=64 + TransferTimeEstimator）与
  迷宫地图病态率（15/16 截断，呼应 P1 的"15/28 孪生未完工集中在 K=6 与 mk01-03"）。
这为主结果的稳健性提供了第三方实现证据，可在论文 reproducibility 脚注引用。
