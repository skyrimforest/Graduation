# 一、核心底层问题
## 1. 双层决策架构
工厂存在两层独立优化的决策模块，各司其职、互不连通：
- **FJSP（柔性车间调度）**：决策工件加工机器、工序加工顺序，仅以加工时间为优化目标；
- **MAPF（多智能体路径规划）**：决策AGV跨机器搬运路径，仅以路径通行效率为优化目标。

## 2. 核心矛盾：搬运动作割裂耦合
FJSP下达跨机器搬运指令（物料从A机器搬运至B机器），由MAPF负责落地执行。
两大模块独立优化、信息隔离，**搬运衔接环节无人统筹**，最终产生严重**耦合损失**。

## 3. 三类核心耦合损失
1. **距离盲区**：FJSP仅考量加工时效，优先选择加工最快的远端机器，忽视AGV长距离搬运耗时，全局总工期反而增加；
2. **时序错位**：FJSP规划物料送达时间与AGV实际运输时序不匹配，出现机器空闲等待、物料堆积拥堵两类浪费；
3. **拥堵聚集**：FJSP集中下发同区域搬运任务，多台AGV抢占窄通道等受限路网，引发通行阻塞、作业卡顿。

---

# 二、损失产生根源与优化介入点
## 1. 信息流传递逻辑
FJSP → 下发搬运请求 → 分配器Assigner → 输出分配方案 → MAPF路径执行
信息单向流动，上游无法感知下游约束，下游无法反向约束上游决策。

## 2. 三层优化介入方案
| 介入模块 | 解决核心损失 | 优化落地方式 |
|----------|--------------|--------------|
| FJSP（增加运输感知） | 距离盲区 | 机器选择阶段，将运输距离、搬运耗时纳入代价函数联合评估 |
| Assigner（增加实时感知） | 时序错位、拥堵聚集 | 任务分配时，实时结合机器队列负载、AGV位置分布、路网状态做匹配 |
| MAPF（信息反向反馈） | 路网拥堵 | 搭建反向通信架构，将实时拥堵数据回传上游调度层，辅助决策修正 |

# 三、核心结论判断
1. **距离盲区为最大损失源**
搬运路程由FJSP机器选择**源头锁定**，后续分配、路径优化无法抵消远距离搬运的硬性耗时；且改造成本最低，仅需在FJSP代价函数中新增运输维度即可落地。

2. **Assigner核心价值：实时动态适配**
即便FJSP输出合理调度方案，现场仍存在AGV匹配、设备负载、路网动态变化等实时问题；合理的任务分配，可有效缓解时序错位与路网拥堵。

3. **最简完整研究方案（基础必做）**
- 步骤1：改造FJSP，引入运输代价感知，从源头规避远距离无效搬运，根治距离盲区问题；
- 步骤2：控制变量实验，对比「有无运输感知」两组方案，量化耦合效率优化效果；
- 研究闭环：论证**传统FJSP-MAPF解耦架构的缺陷**，验证运输感知调度的有效性，形成完整创新贡献。

4. **进阶优化方案（加分拓展）**
在基础方案之上，叠加**学习型Assigner**，解决复杂场景下的动态匹配问题；时间有限时可作为补充内容，不影响论文核心逻辑。

# 四、多FJSP & MAPF算法的研究价值
## 1. 核心逻辑
并非为堆砌算法，而是**问题具备场景差异性**：不同FJSP、MAPF算法组合，会产生完全不同的空间分布、时序特征、拥堵特征，固定规则分配器无法全局适配。

## 2. 不同算法组合的差异化特征
### （1）FJSP算法差异
- 最优精确解：全局加工最优，任务高度聚集，易引发局部路网拥堵；
- PSO/DE等启发式算法：近优调度，任务分布分散，搬运距离略增，但拥堵风险更低。

### （2）MAPF算法差异
- A*传统路径规划：路径确定性强、行为可预测，便于规则化分配；
- 学习型路径规划：运动行为不确定，对分配器鲁棒性要求更高。

## 3. 学习型Assigner的核心优势
固定规则分配器（就近分配、负载均衡等）仅适配单一特定场景；
**学习型Assigner**通过多场景数据训练，自主学习多类启发式策略，可根据实时环境自动切换、组合规则：
- 设备空闲：优先就近AGV分配；
- 机器满载：规避高负载作业区域；
- 紧急工序：优先高优先级物料搬运；
- 路网拥挤：分散AGV任务，均衡路网负载。

# 五、完整论文逻辑链
1. 现象观察：FJSP与MAPF独立求解，引发跨环节耦合损失；
2. 问题分析：Assigner作为耦合核心接口，传统固定启发式规则存在场景局限性；
3. 实验论证：多类FJSP-MAPF组合对照实验，证明单一分配策略无法适配全场景；
4. 方案提出：两步协同优化
   - 源头优化：构建运输感知FJSP，从调度端削减无效搬运；
   - 实时优化：设计学习型Assigner，适配多算法组合动态场景；
5. 结果验证：在全算法组合场景下，学习型分配器全面优于传统启发式基线。

# 六、工程落地实现路线
1. **数据采集**
基于现有4类FJSP、2类MAPF算法，穷举多组组合进行仿真迭代；逐步采集环境观测值、分配决策数据、耦合评价指标，构建多场景数据集。

2. **模型训练**
采用行为克隆（BC）训练；以优质分配样本为标签，向量化环境观测信息为输入，输出AGV任务分配打分模型。

3. **对比评估**
将训练完成的学习型Assigner接入协同调度框架，在全部FJSP-MAPF组合场景中测试，与9类传统启发式分配算法做全面量化对比。

4. **算法价值闭环**
多类FJSP、MAPF算法，既是模型训练的场景来源，也是方案通用性的测试矩阵，支撑论文结论的严谨性与普适性。
