# 切换因果分析：前沿调研与三层识别设计（2026-08-26）

> 回答的问题：自适应日志"切换前后聚合指标对比"有选择偏差——有没有
> 比较干净、没有（或几乎没有）隐患的方法？
> 上位文档：`20260826_总体设计精简版.md` §7.5；tex §7.5 已同步更新。

---

## 0. 一句话结论

**严格"无隐患"的方法不存在——任何方法都有估计量（estimand）边界；但在
我们的仿真器内，"配对克隆 + 同 Tape 重放"是因果推断意义上最接近无隐患
的**：反事实被仿真*实现*而非被统计*估计*，因此不依赖任何不可检验的识别
假设（无混杂、重叠、SUTVA）。剩余边界全部是物理性/工程性的（保真度、
CP-SAT 非确定性、后续策略定义），可显式处理。这正是学界所说的
Digital Twin Counterfactual + Common Random Numbers 配对。

## 1. 隐患从哪来：观测因果推断的根本约束

因果推断的经典难题：反事实不可观测，只能靠**假设**（unconfoundedness：
"选择换/不换与潜在结果无关"）去估计。自适应日志前后对比的隐患清单：
选择偏差（系统只在自认为有利时换）、时间趋势（指标本来就在变）、均值
回归（往往在指标异常差时触发切换，之后自然回弹）、episode 内干涉
（前一次切换影响后一次）。无仿真器世界的主流工具——事件研究/中断时间
序列、DiD、合成控制（含 SDID）、Causal Impact——全都只能在假设下*缓解*
而非消除这些问题。

## 2. 方法阶梯（按识别强度从弱到强）

### L0 前后对比 / 事件研究（描述性）
只作描述，标注偏差来源。论文中保留为"系统行为可视化"（F3 事件研究面板）。

### L1 随机化自然实验（golden trace round-1）
切换决策均匀随机 → 分配机制已知且无混杂。剩余三个诚实局限：
1. **功效有限**：K=8 × 每 trace 决策点数；
2. **估计量受限**：估计的是"随机后续策略下"的切换效应（见 §4）；
3. **覆盖受限**：只覆盖随机策略可达的状态分布（off-support 不外推）。

### L2 配对克隆 + 同 Tape 重放（主力推荐）★
从随机轨迹（或分层抽样）取决策根 → 克隆快照 → **同一外生 Tape** 下分别
执行 keep 与 switch 至终局 → 个体级配对差分 Δ。
- **同 Tape = Common Random Numbers（CRN）**：经典方差缩减技术，配对
  差分的方差远低于独立采样（交通/排队仿真文献常见 50%+ 缩减）；
- **反事实被实现而非估计**：对应对前沿的 Digital Twin Counterfactual
  Framework（DTCF，arXiv 2604.01325）——把仿真器形式化为潜在结果框架内
  的随机映射，反事实世界直接由孪生体仿真出来；
- **个体级 Δ → CATE**：每个决策根都有自己的真 Δ，按状态特征分层即回答
  "何种状态下切换有利"（何时换）；特征归因（哪些聚合指标通道承载差异）
  回答"为何换"，归因须经消融验证防事后合理化；
- **剩余边界（全部工程性）**：
  1. 仿真保真度是前提 → M-A0 前置门（已在计划内）；
  2. **CP-SAT 是 wall-clock 求解器（deterministic=False）**：同输入不保证
     同输出，会破坏配对 → 含 CP-SAT 的决策根排除或增补 Tape 数；
  3. **后续策略必须显式定义**（见 §4），不同后续策略是不同因果量；
  4. 多指标同时检验 → FDR 控制；决策根按 episode 聚类 → cluster
     bootstrap 求区间。
- **成本**：每对 = 2 次终局 rollout。注意这与已降级的"oracle 标签训练
  管线"不同：那是全量逐决策点标签生成（future work），这是**抽样子集上
  的分析实验**——golden trace 协议里 `decision_roots/*.pkl` 本来就是为
  "可复放/oracle 重算"存的，直接复用。

### L3 策略级 RCT（E1 主实验本身）
"我们的切换策略整体是否更好"由 E1 回答：72 spec × 同 spec 同 Tape 的
配对随机实验。策略级问题不需要观测方法，实验设计已经是金标准。

### L4 离策略评估（OPE，为未来留门）
若未来要从自适应策略**自己的日志**估计反事实策略值（无法重跑基线的
场景），标准工具是 importance sampling / doubly-robust（DR）/ FQE
（Uehara et al. 综述；Dudík et al. DR；Voloshin et al. 实证比较）。
前提：**行为策略必须有随机性且记录动作概率**。
→ **现在就要做的低成本设计动作**：shadow 运行的切换决策注入 ε 随机化
并在 decision_log 里记录动作概率。不记录，未来 OPE 不可用。

### 参考（本阶段不采用）
- **Switchback 实验**（Bojinov et al., Management Science 2023）：干扰下
  的时间切换实验设计，用于在线部署评估；仿真内因有克隆而不需要；
- **合成控制/Synthetic Interventions/Causal Impact**：无仿真器时的反事实
  轨迹估计，此处被 L2 严格支配，仅在相关工作里引用定位；
- **CATE 元学习器**（X-learner、DR-learner、causal forest）：样本量
  数百个决策根时先分层+精确配对，森林法作敏感性检查。

## 3. 论文因果章的三层设计（已写入 tex §7.5）

```text
主力    L2 配对克隆反事实：个体级 Δ 分布 + 按状态特征分层 CATE（何时换）
        + 通道归因（为何换，消融背书）
交叉验证 L1 随机自然实验：与 L2 结论方向一致 = 稳健性证据
描述补充 L0 事件研究：自适应日志，显式标注选择偏差
策略级   L3 = E1 配对 RCT（不走观测层）
留门     L4：shadow 加 ε 随机化 + 记录 propensity
```

## 4. 估计量必须显式定义：三个不同的"切换效应"

"切换的效果"依赖于**切换之后怎么做**（continuation policy），这是最容易被
忽略的隐患（即使做了随机化也在）：

| estimand | 定义 | 可由谁算 |
|---|---|---|
| τ_keep | 此刻切换，之后 KEEP 到底 | L2 精确（确定性后续） |
| τ_rand | 此刻切换，之后随机策略到底 | L2（对后续采样平均）或 L1 |
| τ_adapt | 此刻切换，之后自适应策略到底 | 需嵌入 V0/V1 运行或 L4 OPE |

建议：论文主口径 = τ_keep（机制最干净），τ_rand 作与 L1 可比的桥，
τ_adapt 属于策略级问题归 E1/L4。
