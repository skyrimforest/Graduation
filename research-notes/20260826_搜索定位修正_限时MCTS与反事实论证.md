# 搜索定位修正：限时 MCTS 求解器 + 反事实论证（2026-08-26）

> 状态：定位修正记录（用户指示，经分析采纳）
> 修正对象：`20260826_阶段目标与总体设计.md`（rev2 §1 主目标的"搜索是标注器不是控制器"表述）

## 1. 修正了什么

此前表述："搜索从控制器降格为标注器"。

修正后的定位：**同一个 anytime 搜索算法，两个工作点**：

```text
限定时间  →  在线求解器：产出可执行的基础解（文章主角算法、LLM 的 baseline）
不限时间  →  golden truth 生成器：完全枚举级真值，作为数据/打分来源
```

我此前的错误在于把 Phase 7 的负结果过度推广了。严格地说：

| 搜索类型 | 是什么 | Phase 7 结论 |
|---|---|---|
| **元级搜索**（在算子组合空间里选"用哪个求解器"） | Periodic-30 + Depth-2 MCTS 元调度 | **被证伪**（劣于一次浅搜与静态映射） |
| **对象级搜索**（在调度解空间里直接构造"工序→机器/顺序/指派"） | 限时 MCTS/BFS 求解闭环调度本身 | **未被检验**，不冲突 |

Phase 7 证伪的是前者。而且 Phase 7 同时显示 **One-Shot（决策点一次浅搜）是好的**——对象级限时 MCTS 恰好就是"决策点上的 anytime 搜索"，与全部已有证据相容。runtime continuity 约束依然适用：搜索产出的解应温接当前 incumbent，而非冷重选。

## 2. 文章最终形态（目标）

```text
主角算法：限定时间的闭环 MCTS
    输入：当前决策状态 s̃（含求解器上下文）+ 时间预算
    输出：可执行的基础解（工序指派/排序），anytime 语义

论证层：反事实解释
    用同状态克隆 + Tape（既有基础设施）回答：
    "为什么这一轮这样执行比较好"
    = 对比被拒候选的 Δ，指出决策依据（哪些聚合特征驱动了差异）

消融：聚合特征选取消融
    论证层引用的特征组逐组消融（drop-one / 现在时 vs 前瞻），
    验证"解释引用的特征确实承载决策信息"

Baseline 角色（对 LLM 路线）：
    限时 MCTS = LLM 联合调度器的强 baseline（LLM 要打平/超越的对象）
    不限时 MCTS/穷举 = 训练数据与打分来源（golden truth）
```

三层关系：MCTS 产出解 → 反事实层论证解 → 不限时版给真值打分。同一套
转移引擎/Tape/竞赛评估基础设施同时服务三层。

## 3. 路线图影响（相对 rev2 的变更）

新增/调整里程碑（插入 M-C1 之后）：

```text
M-E1 对象级限时 MCTS V0                     【新增，核心】
    在闭环仿真上直接搜索调度决策（非算子选择）。
    复用 TransitionEngine 做节点展开（或轻量化 rollout）；
    遵守 runtime continuity（温接 incumbent）；
    anytime：预算即停，输出当前最优解 + 置信状态。
    与 Racing 的关系：Racing 保留为"候选评估器"（M-C0 组合空间的
    竞赛），MCTS 是"解构造器"；二者可组合（MCTS 内部用 Racing 评节点）。

M-E2 反事实论证层                           【新增】
    对 MCTS 选定解生成解释：Top-K 被拒候选的 Δ 分解 +
    决策特征归因。输出人可读论证 + 机器可读记录。

M-E3 聚合特征选取消融                       【新增】
    论证层特征组 drop-one / 增量消融（沿用 G0–G5 纪律）。

M-A4 语义调整                               【调整】
    "不限时 MCTS/穷举 → golden truth"成为正式打分管线；
    删失/截断语义协议覆盖两个工作点。
```

不变的部分：M-A1/A2（干净根、t>0 决策点）仍是数据前置；M-D1 切换策略
仍然等待检测器；LLM 路线仍暂缓但本算法被登记为其 baseline。

## 4. 风险与边界（诚实记录）

1. 对象级 MCTS 在闭环环境上可能是 Phase 7 的"深搜陷阱"重演——但对象级
   搜索的展开是"构造解"而非"重复调用求解器"，计算画像不同；需用
   One-Shot/uniform 作严格基线，若不显著优于一次浅搜则如实报告。
2. 反事实论证层的"解释忠实度"（explanation faithfulness）需要消融支撑，
   否则只是事后合理化——这正是 M-E3 的目的。
3. 不限时 MCTS 收敛到真值的前提仍是保真度前置门（M-A0）与统一截断语义。
4. 限时 MCTS 作为 LLM baseline 的公平性：同一环境、同一动作空间、同一
   评估口径，禁止给 LLM 更宽松的预算。
