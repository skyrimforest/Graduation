## 1. 主目标（不许漂移的锚）

```text
读取当前场上决策状态（含求解器上下文）
  → 计算状态指标（硬计算优先，网络后置）
  → 生成合法算子组合候选（显式动作空间契约）
  → 预算受限的广度优先候选竞赛（Racing，统一 horizon）
  → 截断仿真得到 Oracle ΔQ
  → 切换决策：G = Δ − λ·切换成本，LCB(G) > τ 才切，含迟滞
  → 闭环 episode 评估收尾
```

配套的 ground truth 主张：**搜索是标注器，不是控制器**。Phase 7 已证伪
"在线滚动深度 MCTS 控制"（NO-GO）；有效成分（一次性浅探测、runtime
continuity、uniform 分配）是本阶段设计的证据基础。

研究问题闭环链（论文主线）：

```text
什么状态 → 为什么这个算子更好 → 搜索证明确实更好
→ 改善是否足以支付切换成本 → 是否切换 → 连续运行是否真正改善总体调度
```

## 4. 里程碑（rev2 优先级链）

```text
M-A0 → M-A1/A2 → M-C0 → M-A4 → M-F1 → M-B1(M6) → M-C1 → M-D1 → M-D2
```

### M-A0 保真度前置门（半天）
把既有复放证据形式化为 oracle 运行的 prerequisite：clone + same action +
same tape → 逐项核对 next-state hash / 事件序列 / job 完成 / AGV 位置 /
机器可用性 / objective。复用 verify_phase7_replay，不新建机制。
**产出：oracle 运行开跑前的强制检查清单与自动化脚本。**

### M-A1 干净根重采（半天，无依赖）
修复后契约下重新生成 t=0 根 + 与 P0 清单逐字段比对审计。

### M-A2 t>0 决策根采集预注册（1-2 天，需评审，关键路径）
冻结采样时刻/数量/分层（不触 confirmation split）。
交互域、差分特征、solver 上下文动态全部依赖此步。

### M-C0 算子组合契约（1 天）
整合既有件为正式 contract（多数是整合不是新写）：
`OperatorCombination = {fjsp_solver, mapf_solver, assigner, parameter_profile,
warm/cold, compatibility_mask, estimated_runtime, switching_cost,
service_dependency}` + 特殊动作 KEEP。合法性掩码基于 solver manifest
capabilities（已就位）。**产出：动作空间清单文件 + 合法性校验 + 切换
成本默认表。**

### M-A4 Oracle 数学定案 + 干净重算（M-A1/A2 后）
固定公式（objective 越小越好）：

```text
Q_H(s,a) = E_ξ[ J(Rollout(s,a,H,ξ)) ]        # s 含求解器上下文
Δ(s,a)   = Q_H(s, keep) − Q_H(s, a)
G(s,a)   = Δ(s,a) − λ·C_switch(s,a)          # 预测目标是 G，不是裸 Δ
```

截断语义三条铁律：① 统一 horizon——同一轮所有候选同 H，预算只控制
候选×tape 数量；② 截断 outcome 拆字段记录（completion_status /
objective_so_far / remaining_work / simulation_time / solver_runtime），
禁止单一罚值冒充真值；③ 统计分层报告（完成率 / 终局-only / 删失口径）。
分级成本门控照 Phase 7 复盘执行。

### M-F1 求解器上下文特征（1 天）
把 `control_context` 引入特征层：当前 recipe 标识、运行时长、warm/cold、
incumbent 可观测量、最近改进斜率、fallback/no-path 率差分。
**理由（审阅正确指出）：runtime continuity 是 Phase 7 强支持机制，
不进特征就会制造"同 X 不同最优动作"的 label noise。**

### M-B1 M6 交互底座（1 天，纯主线）
参考路径派生实体/边级冲突边、跟车边、corridor 占用。
7.7 指认的表征瓶颈核心嫌疑。

### M-C1 预算受限候选竞赛（1-2 天，纯工程）
V1 = Budgeted Racing / Successive Halving：round 1 全候选 × 少 tape ×
短 H（统一）→ 淘汰明显劣势 → 幸存者 × 更多 tape × 更长 H（统一）→
预算尽或置信足。并行评估。价值模型当前只做**候选排序先验**，
不直接决定答案。V2（Beam，序列决策）V3（value-guided MCTS 作 oracle
加速器）本轮不实现，仅占位。

### M-D1 切换策略（M-A4 + M-F1 后）
决策规则：`LCB(G) > τ` 才切；整合既有 hysteresis/cooldown
（trigger_policy.py）防抖动；切换成本表来自 M-C0。
任何在线激活需新预注册；shadow 先行。

### M-D2 闭环评估（收尾 gate）
oracle / 预测器 / 切换策略放回完整 episode 连续跑，报告
closed-loop makespan/cost。复用 Phase 7 闭环配对机制与统计口径。

### 降级项
- M-A3（污染根 G0 vs G2）：cheap sanity check，半天封顶，不阻塞主线；
- B 路线全部（ObservationLanguage、模仿探针）：暂缓，未来任务。

## 5. 纪律与风险边界

1. **汇报锚定主目标**：进展必须对照第 1 节闭环链与第 4 节优先级链，
   禁止子任务冒充主线进展。
2. **旧结论边界**：7.6B/7.7 "表征不可用"基于污染特征，P1a 后复检；
   Phase 7 outcome 级结论不受影响；冻结工件不回改。
3. **词表冻结**：schema 版本化；离散边界、归一化统计从 dev split 冻结。
4. **预注册门槛**：M-A2 采样、任何选择器/切换策略激活、confirmation
   复用、RL/GRPO、Phase 8——先协议评审。
5. **成本纪律**：oracle 类运行分级门控（ETA 校准先行；预计超 2 小时
   或 10GB 暂停确认）；stateless 类消融单独限量。
