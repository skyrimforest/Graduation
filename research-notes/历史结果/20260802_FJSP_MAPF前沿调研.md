# FJSP + MAPF 联合优化前沿调研

**调研日期：2026-08-02**

## 1. 问题定义

目标场景包含一组工件、可替代加工机器和搬运小车。每个工件由有前序关系的工序组成；相邻工序被分配到不同机器时产生搬运任务；小车负责取料、运输和交付，机器在物料到达后加工。最终目标是最小化包含加工、装卸、空驶、运输、等待、绕行和冲突消解在内的端到端 makespan。

该问题同时包含四类强耦合决策：

1. **机器选择**：每道工序分配给哪台候选机器；
2. **工序排序**：每台机器按什么顺序加工；
3. **运输任务分配**：搬运任务分配给哪辆 AGV/AMR；
4. **无冲突时空路径**：车辆何时经过哪些节点和边，避免顶点冲突、对向边冲突、拥堵与死锁。

文献尚未形成统一名称。本文建议使用：

- `FJSP-MAPF`：强调柔性作业车间与多智能体路径规划的结合；
- `FJSP-PC-TAPF`：强调任务前序约束、任务分配与路径规划；
- `Integrated FJSP with Conflict-Free Multi-Robot Transportation`：适合作为正式论文问题描述。

## 2. 三条相关研究线

### 2.1 FJSP with transportation

常见名称包括 `FJSP-T`、`FJSPT` 和 `FJSP_PT`。该方向通常联合决定机器、工序和车辆，但大量工作仍将运输表示为机器间固定时间矩阵，或者只对车辆进行资源排序，不显式展开车间路网中的时空冲突。

2024 年 EJOR 工作扩展析取图，将运输操作和车辆路线纳入 FJSP，使用禁忌搜索求解并发布新算例，是当前重要的 FJSPT 基线：

- Lucas Berterottiere, Stephane Dauzere-Peres, Claude Yugma, *Flexible job-shop scheduling with transportation resources*, EJOR 2024. DOI: [10.1016/j.ejor.2023.07.036](https://doi.org/10.1016/j.ejor.2023.07.036)

2025 年综述归纳了 FJSP_PT 的假设、约束、目标、基准和算法类别，是系统了解该方向的主要入口：

- Bin Xin et al., *A review of flexible job shop scheduling problems considering transportation vehicles*, FITEE 2025. DOI: [10.1631/FITEE.2300795](https://doi.org/10.1631/FITEE.2300795)

### 2.2 MAPF、TAPF 与 MAPD

MAPF 研究多车从起点到目标点的无碰撞路径；TAPF 进一步联合任务/目标分配；MAPD 研究连续到达的取送任务。制造任务还需要前序约束、加工驻留时间、时间窗和共享工作站容量。

2024 年 AAMAS 的 `TAPF-PTC` 将任务分配、前序约束、时间约束和 CBS 路径搜索统一，给出完备、最优和有界次优版本：

- Yu Quan Chong, Jiaoyang Li, Katia Sycara, *Optimal Task Assignment and Path Planning using Conflict-Based Search with Precedence and Temporal Constraints*, AAMAS 2024. [arXiv:2402.08772](https://arxiv.org/abs/2402.08772)

2024 年面向智能制造的 `PC-TAPF` 工作使用 Regret-based Search 联合运输任务插入与冲突路径规划，直接处理制造任务的前序关系：

- Shuo Liu et al., *An Integrated Approach to Precedence-Constrained Multi-Agent Task Assignment and Path Finding for Mobile Robots in Smart Manufacturing*, Applied Sciences 2024. DOI: [10.3390/app14073094](https://doi.org/10.3390/app14073094)

这类工作适合作为运输层求解器，但通常不决定工序的候选机器和机器队列。

### 2.3 生产调度与 MAPF 的真正交叉

真正同时讨论加工调度、车辆分配和冲突路径的工作仍然较少。

| 工作 | 机器柔性 | 车辆分配 | 显式冲突路径 | 双向反馈 | 主要边界 |
|---|---:|---:|---:|---:|---|
| Sensors 2023 conflict-free FJSP | 是 | 是 | 时间窗 Dijkstra | 弱 | 混合 GA 后接路径规划，整体偏分层 |
| PC-TAPF 2024 | 否 | 是 | 是 | 不适用 | 不决定机器选择和加工队列 |
| CBS-TA-PTC 2024 | 否 | 是 | 是 | 不适用 | 精确但扩展性有限，不含 FJSP |
| ACES 2025 | 是 | 是 | 是 | 联合建模 | 优化循环吞吐量，不是有限订单 makespan |
| IEEE TSMC 2025 | 是 | 是 | 否/弱 | 在线调度 | 重点是动态 AGV 分配和扰动，不是 MAPF |
| Sensors 2026 DQN + PBS | 否，主要是 JSP | 是 | PBS | 分层协作 | 没有证明全局联合最优 |
| CP FJSPT-H 2026 | 是 | 是 | 路径预留 | 联合建模 | 固定路径、分区与 handoff，不是通用 MAPF |

代表论文如下。

#### Sensors 2023：FJSP + conflict-free routing

混合遗传算法产生生产计划，基于时间窗的 Dijkstra 计算 AGV 路径，并在 82 个算例及实际车间中验证：

- Jiachen Sun et al., *An Approach to Integrated Scheduling of Flexible Job-Shop Considering Conflict-Free Routing Problems*, Sensors 2023. DOI: [10.3390/s23094526](https://doi.org/10.3390/s23094526)

其价值是明确把冲突路径纳入 FJSP；局限是生产计划与路径规划仍以阶段式方式协调。

#### ACES 2025：机器分配 + MAPF 的联合 MILP

ACES 联合优化制造过程到机器的映射和移动机器人路径，使用可循环运输计划控制 MILP 规模，并在 6 个工业场景上评估：

- Christopher Leet, Aidan Sciortino, Sven Koenig, *Jointly Assigning Processes to Machines and Generating Plans for Autonomous Mobile Robots in a Smart Factory*. [arXiv:2502.21101](https://arxiv.org/abs/2502.21101)

它与本项目结构高度接近，但目标是重复生产的稳态 throughput，不是有限工件集合的端到端 makespan。

#### IEEE TSMC 2025：动态 FJSP-AGV 的 MARL

多智能体架构分别完成任务选择、机器分配和 AGV 分配，并处理四类动态扰动：

- Yuxin Li et al., *Real-Time Scheduling for Flexible Job Shop With AGVs Using Multiagent Reinforcement Learning and Efficient Action Decoding*, IEEE TSMC 2025. DOI: [10.1109/TSMC.2024.3520381](https://doi.org/10.1109/TSMC.2024.3520381)

该工作说明“GNN/MARL + 机器/AGV 联合选择”已经较拥挤。其核心不是显式时空路径冲突，因此本项目不应再把普通 AGV 分配 RL 作为主要创新。

#### Sensors 2026：DQN + PBS

该工作建立含运输与顶点/边冲突约束的离散时间模型，上层使用改进 DQN 排产，下层使用 Priority-Based Search 生成无冲突路径：

- Ruiqi Li et al., *A New Framework for Job Shop Integrated Scheduling and Vehicle Path Planning Problem*, Sensors 2026. DOI: [10.3390/s26020543](https://doi.org/10.3390/s26020543)

它是 SkyEngine 需要正面对比的最近邻工作。差异不能只写“我们也有闭环环境”，而应落到：

- 完整 FJSP 而非固定机器 JSP；
- 路径执行不确定性是否反向触发机器/工序重调度；
- 是否在受限 MAPF 查询预算下优化质量与计算成本；
- 是否报告组合外、地图外和拥堵外泛化。

#### CP FJSPT-H 2026：异构车辆、分区与交接

该工作提出 arc-based 和 operation-embedded 两种 CP 模型，加入异构车辆、区域限制、跨区 handoff 和 book-and-release 路径预留：

- Arnovi Moinuddin, El Mehdi Er Raqabi, Pascal Van Hentenryck, *Scheduling and Routing in the Flexible Job Shop with Heterogeneous Transbots and Zoning: A Constraint Programming Approach*. [arXiv:2604.24483](https://arxiv.org/abs/2604.24483)

它代表精确/约束建模方向的最新进展，也说明单纯宣称“首次联合 FJSP 和路径”已经不成立。其路径为固定路线和资源预留，不是动态通用 MAPF。

## 3. 当前算法趋势

### 3.1 从巨型单体模型转向分解协调

将机器、工序、车辆、节点和时间全部展开成一个 MILP/CP 模型，变量规模会快速增长。更可扩展的路线是：

1. 主问题决定机器、工序顺序、运输任务释放时间和初步车辆分配；
2. MAPF 子问题验证时空可行性并返回真实延迟或不可行冲突；
3. 主问题通过 Benders cut、LNS 邻域、时间窗修正或滚动重调度吸收反馈。

### 3.2 学习器负责决策，搜索器负责安全与可行性

近年更稳健的混合路线不是让网络逐步控制每辆车，而是：

- GNN/Transformer/RL 决定机器、任务优先级、AGV 分配或重规划触发；
- CBS/PBS/ECBS/SIPP/RHCR 等求解器负责无冲突路径；
- 小规模用 CP-SAT/MILP 提供最优值或高质量监督。

### 3.3 从确定运输时间转向风险与执行偏差

固定距离矩阵只描述空载或无冲突最短路。真实运输时间受车辆当前位置、路段占用、任务波次、窄通道和冲突消解影响，应建模为条件分布：

\[
T_{ij}\mid s \sim p(T\mid \text{task},\text{AGV},\text{map},\text{congestion})
\]

仅预测均值不足以支持高风险重调度。更有研究价值的是 P50/P90、CVaR、置信区间及其校准。

### 3.4 计算预算成为可比较目标

“每个事件都调用精确 MAPF 并全量重排”通常计算代价过高；“从不调用”又会低估拥堵。值得研究的是在固定查询预算下选择何时调用昂贵的 MAPF oracle，使 makespan 与求解成本形成更优 Pareto 前沿。

## 4. 仍未解决的关键空白

1. **路径代价如何反向改变机器选择。** 多数方法只让路径影响车辆时间，没有重新打开机器分配或工序排序决策。
2. **有限订单 makespan 下的预算化闭环。** ACES 解决稳态 throughput，CP 方法偏离线精确求解，在线有限订单的查询预算仍缺乏系统研究。
3. **统一可复现基准。** FJSPT 算例通常只有时间矩阵，MAPF 基准通常没有机器和工序，需要标准化组合实例。
4. **执行模型真实性。** 离散栅格模型常忽略方向、转弯、加减速、车体尺寸、装卸驻留和工作站缓冲。
5. **不确定性校准。** 运输时延预测是否校准、是否跨地图/车数/负载泛化，公开证据较少。
6. **质量与算力公平比较。** 不同方法调用 MAPF 和重调度的次数差异很大，仅比较 makespan 不公平。

## 5. 对 SkyEngine 的直接含义

### 应保留

- FJSP、AGV 分配和网格执行的统一事件环境；
- 可插拔 JobSolver、RouteSolver 和 Assigner；
- 路径执行结果回写工序到达和机器加工状态；
- 静态、弱耦合和闭环设置的系统性对照。

### 应降级

- “首个 FJSP-MAPF 联合环境”；
- “首个闭环联合调度”；
- “普通 GNN/MARL AGV 分配”；
- 在没有严格共同动作空间和消融前，将多专家蒸馏/GRPO列为主贡献。

### 应升级

建议把论文核心从“统一环境 + 多专家 Assigner”收敛为：

> **受限 MAPF 查询预算下的风险感知闭环滚动 FJSP 调度。**

该方向既承接现有 `TransferTimeEstimator`、Coordinator、指标和事件环境，也与 2026 年 DQN+PBS、CP-FJSPT-H 和 ACES 形成清晰差异。

## 6. 推荐评价协议

### 主对照

1. 静态最短路运输时间；
2. 历史均值校正；
3. 每次事件均调用 MAPF 并重调度；
4. 固定周期调用 MAPF；
5. 风险触发调用 MAPF；
6. 预算感知风险触发。

### 主指标

- 真实端到端 makespan；
- MAPF oracle 调用次数与总求解时间；
- 机器等待物料时间；
- AGV 等待/空驶/载货时间；
- 运输时间预测 MAE、P90 覆盖率和校准误差；
- episode 完成率、死锁率和超时率。

### 泛化维度

- 未见 FJSP 实例；
- 未见地图拓扑；
- 未见 AGV 数；
- 未见任务密度和跨区运输比例；
- 未见 JobSolver × RouteSolver 组合。
