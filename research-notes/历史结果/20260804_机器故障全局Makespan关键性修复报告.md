# 机器故障全局 Makespan 关键性修复报告

## 一、修复目标

旧 v3 直接将局部 job completion 提前量映射为系统收益，导致：

```text
k2:   真实 +13.35
mk01: 真实 -22.73
```

本轮新增全局计划投影，显式计算所有 job 的 projected completion 和 global
makespan。

## 二、实现

在线计划图包括：

- 未承诺 PENDING operations；
- job precedence；
- solver artifact 的 machine operation order；
- 机器间运输；
- 故障维修和当前物理可用时间；
- branch-specific machine assignment 和 processing time。

分别投影：

```text
wait projected global makespan
reassignment projected global makespan
```

两者差值作为在线估计。全部输入均来自 branch point，不使用 terminal outcome
或 realized critical path。

新增互斥动作：

```text
global_makespan_operation_machine_reassignment
```

97 项 Docker 回归通过。

## 三、projection v1

| 指标 | 结果 | Gate |
|---|---:|---:|
| Coverage | 76.7% | 95% |
| Pearson | 0.288 | 0.30 |
| Sign accuracy | 63.0% | 65% |
| Selection disagreement clusters | 10 | 10 |

28 个 unavailable units 全来自 `mk01`。原因是 planned-start ties 被任意排序后
制造了原计划不存在的 precedence cycle。

## 五、结论

全局投影修复了概念错误：

> 非关键 job 的局部提前不再自动计为 makespan 收益。

但固定计划图仍无法可靠复现真实在线执行，主要缺失：

1. AGV 到达驱动的机器队列动态重排；
2. committed operation 的完成时间传播；
3. 多 AGV 竞争改变的运输先后；
4. 实际执行对初始 CP-SAT operation order 的偏离。

新旧选择已有 11 个独立分歧 clusters，但 Estimator Gate 未通过，因此没有运行
新动作 terminal rollout。

## 六、研究边界

本轮结果证明继续增加静态成本项的收益有限。后续若仍推进机器故障，应转向：

```text
轻量级在线 rollout / model-based lookahead
```

即从 branch state 运行短视物理仿真，而不是继续手工叠加解析成本。但在设计严格
的计算预算和独立验证集前，Causal、BNN、Offline RL 和 CBQ-IQL 仍保持阻塞。
