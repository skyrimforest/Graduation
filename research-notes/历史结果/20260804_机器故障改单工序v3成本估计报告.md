# 机器故障改单工序 v3 成本估计报告

## 一、结论

v3 完成了从“局部工序完工时间”到“端到端物理成本分解”的升级，但仍未通过
Estimator Gate 或 Selector Value Gate。

核心结果：

```text
v3 raw Pearson:       +0.268
v3 raw sign accuracy: 53.3%
v3 policy mean:       +3.22
v3 policy 95% CI:     [-1.86, 8.81]
```

相比 v1/v2，v3 首次同时取得明显更高相关性和正策略均值，但统计证据不足。

## 二、v3 增加了什么

v3 仍评估同一个单工序改派 treatment，不改变动作结果。新增在线物理量：

1. AGV empty/loaded 路径历史 occupancy 与 transit；
2. 当前路线 AGV 冲突暴露；
3. 故障机器和候选机器的完整未来 commitments；
4. 当前工序到 job 最后一道工序的延迟传播；
5. 从故障机器移除工序的外部性收益；
6. 向候选机器插入工序的外部性成本；
7. transport rebuild 与 route-duration delta。

当前仿真中 PlanRevision 激活不消耗物理时间，因此没有人为添加固定求解惩罚。

## 三、实验设计

开发数据：

- Fattahi `mfjs01`；
- Brandimarte `mk01`；
- Fattahi `mfjs02`；
- Kacem `k2`；
- maze/random；
- seeds 0-4；
- low/medium/high；
- 120 units。

校准方式由按 seed 留一升级为：

```text
leave-one-FJSP-instance-out
```

模型禁止输入 family、instance、topology、seed、severity 和任何 terminal
outcome。

## 五、物理分量解释

| 分量 | Pearson |
|---|---:|
| 候选机器外部性避免 | +0.391 |
| 运输时长优势 | +0.376 |
| 故障机器外部性优势 | +0.330 |
| loaded-route 拥堵优势 | +0.249 |
| job completion 优势 | -0.153 |

完整机器外部性和运输差异确实携带信号，但线性权重在实例间反转，导致留一实例
校准失败。不能将 pooled correlation 包装成可泛化机制。

## 六、为什么暂时失败

当前 `single_operation_reassignment` 的候选机器仍由 v1 局部完工时间排序。
v3 只评估 v1 已经选定的候选，无法回答：

> 同一工序的其它健康候选机器是否具有更低的真实系统成本？

因此当前瓶颈可能位于 treatment 内部的候选机器排序，而不只是 wait/reassign
二分类器。

## 七、下一步

1. 对每个 eligible alternative 计算同一套 v3 物理成本；
2. 比较 v1 candidate 与 v3 candidate 的分歧率和成本分量；
3. 将“v3 候选机器改派”定义为新的、互斥的原子 treatment；
4. 先做小规模同源 terminal 验证；
5. 只有候选排序 Value Gate 通过，才重新训练 wait/reassign selector。

Causal、BNN、Offline RL 和 CBQ-IQL 继续阻塞。
